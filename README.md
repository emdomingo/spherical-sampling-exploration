# Spherical Sampling Exploration

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.XXXXXXX.svg)](https://doi.org/10.5281/zenodo.XXXXXXX)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An exploration of sampling schemes on the sphere and their reconstruction accuracy.

## Notebooks

This repository includes the following notebooks:

| Notebook | Description |
|---|---|
| [`00_mathematical_background.ipynb`](00_mathematical_background.ipynb) | A notebook with mostly markdown blocks that show the background of Spherical Sampling and Spherical Harmonics |
| [`01_classical_grids.ipynb`](01_classical_grids.ipynb) | An exploration of the Classical Grids: DH, GL, and MW |
| [`02_polyhedral_grids.ipynb`](02_polyhedral_grids.ipynb) | An exploration of the Polyhedral Grids: Tetra, Octa, and Icosa |
